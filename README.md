# Siva AI

A mobile-friendly personal AI assistant website starter.

## Features
- ChatGPT-style responsive interface
- New chat and local chat history
- Dark/light mode
- Hindi, Assamese and English friendly UI
- Voice input
- File attachment UI
- Settings panel
- Ready to connect to a real AI backend

## Important
This starter does not include a private API key. For a real AI assistant, connect the frontend to a secure server-side AI endpoint or an open/free model backend.
